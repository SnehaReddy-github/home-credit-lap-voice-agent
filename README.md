# Home Credit – LAP Qualification Voice Agent

## Project Overview
An AI-powered voice agent developed using Retell AI to conduct preliminary customer qualification for a Loan Against Property (LAP) offer of up to ₹75 lakh.

## Objectives
- Verify the customer's identity.
- Explain the LAP offer.
- Collect the required eligibility information.
- Identify disqualifying conditions.
- Route eligible customers to a senior loan expert.

## Eligibility Criteria
1. Property type: Residential, Commercial, or Industrial.
2. Ownership: Sole or Joint.
3. Original property documents must be available.
4. Loan amount: Up to ₹75 lakh.
5. Occupation and income mode: Salaried or Self-employed; bank income is eligible.
6. Estimated property market value.
7. Loan tenure: 3–15 years.

## Key Features
- Customer verification and callback handling.
- Eligibility assessment.
- Disqualification handling.
- Loan amount limit handling.
- Specialist routing for existing property loans or EMI-reduction requests.
- Senior loan expert handoff after successful qualification.

## Technology
- Retell AI
- Large language model prompting
- Voice conversation testing
- Call transcripts and summaries

## Testing
Scenarios include successful qualification, agricultural property, unavailable original documents, cash income, invalid tenure, and loan amounts above ₹75 lakh.

## Project Evidence
The repository will contain the System Prompt, test scenarios, and links to available call recordings and transcripts.

## Disclaimer
The agent performs preliminary qualification only. Final loan approval depends on the lender's verification and lending process.
